### 批量状态挡住图片预览

命令（在本插件目录）：

```sh
npm run test:browser -- --grep 'batch=true'
```

- 修复前实际失败：上边距拖动后 `Expected "20", Received "10"`，重复执行仍失败。
- 最初单张也失败，调查发现测试在 0.1s 缩放动画完成前取坐标。等待真实图片 decode 和动画后，单张通过而批量仍失败；没有把该测试时序问题当作产品根因。
- 浏览器命中探针：相同坐标修复前为 `batch-overlay`；仅临时设置遮罩 `pointer-events:none` 后为 `g-top`，真实拖动后上边距变为 `20`。
- 根因：保存的批量模式会恢复覆盖整块预览的高层不透明遮罩，拦截引导线输入。
- 修复：批量状态改为不拦截事件的小标记；空选中时仍显示操作指引。
- 修复后通过，单张回归也通过。
