# MyFigma 九宫格工具 v2 插件

由旧独立 9-Slice 插件迁移，保留单张／批量转换、四边及统一边距、保留或替换原图、可选重叠、预览缩放／平移及七种语言。旧插件目录不参与构建，也未写入。

## 独立构建与导入

需要 Node.js（本次验证 v24.15.0）和 npm：

```sh
npm ci
npm run build
npm run typecheck
npx playwright install chromium
npm test
```

Figma 桌面端通过开发插件菜单导入本目录的 **`manifest.json`**；其中 `main`／`ui` 指向构建后的 `dist/code.js` 与 `dist/ui.html`，因此先执行构建。无需本地助手、图集导入插件、旧插件、ui-studio 或运行时网络服务。构建只读取仓库的 `tools/figma-project-assets/packages/nine-slice/src/` 并 bundle 到产物。

没有复用旧发布插件的 ID；如 Figma 客户端要求注册 ID，先创建独立开发插件，使用其新 ID，勿覆盖旧发布插件。实际客户端导入尚未验证。

## 使用

1. 在画布选择含图片填充的图层，运行插件。
2. 输入边距或拖动绿色引导线；滚轮缩放，中键或平移模式拖动预览，适配按钮复位。
3. 选中本工具生成的主组件会进入「更新九宫格组件」模式：读取现有边距，修改后原位更新，不创建第二个主组件，实例关联保留。旧版无元数据的组件会先检测切片结构并推导边距；结构无法识别时明确提示且不修改。选中实例时提示定位主组件，不会把实例或既有主组件转换成新组件。
4. 批量模式将同一组参数应用到所有选中图片；状态标记不再遮挡操作。
5. 生成组件。保留原图默认关闭：全部目标生成成功后删除原图；开启后才保留。

保留原图、批量模式和消除缝隙默认关闭；旧版本保存的开启状态会在首次加载时迁移为关闭，之后尊重你的手动选择。编辑现有组件时保留原图/批量不适用，界面会禁用。

边距单位为图层尺寸，不一定等于源图片像素。左右之和必须小于宽度，上下之和必须小于高度；批量先校验所有目标。零边距不生成空切片。

适用范围沿用旧插件：普通、未旋转、单一图片填充、未自定义裁剪的图片图层。复杂裁剪、平铺、多填充、遮罩、特效与 Auto Layout 父级定位不保证视觉兼容。透明图建议关闭消除缝隙。

可编辑组件仅限本工具生成的、由切片矩形组成且共用同一图片填充的组件；人工改造过内部结构、混合图片或多层复杂组件会跳过，不强行修改。组件使用与图集导入插件共用的 `myfigma.nineSlice.v1` 记录：只有实际改动边距或消缝时才把 `override` 标为 true，同时保留导入插件记录的项目参数 `project`；原值提交不会把项目参数误标为人工覆盖。

存在项目参数且当前为人工边距时，编辑状态会显示「人工边距优先」并提供「恢复项目参数」：清除 `override`、按 `project` 原位重建切片，主组件身份与实例关联保留。项目参数缺失或无法应用到当前尺寸时拒绝恢复并保留原切片。导入插件遇到图片变小导致人工边距失效时会跳过该项并提示可恢复后重试。

## 验证

```sh
npm run test:browser -- --grep 'batch=true'
npm run test:browser -- --grep 'small selected'
npm run build && node --test tests/plugin.test.cjs
npm run typecheck
npm test
```

浏览器测试加载构建产物的真实页面，以平台消息输入图片，使用真实鼠标拖动／点击／输入验证交互。生成测试从 `figma.ui.onmessage` 驱动，只在 Figma API 边界使用替身，不测试私有函数。
