# 图集导入工具开发

本文件仅约束本目录下的开发；通用协作与 UI 工作流沿用根目录 `AGENTS.md`。

## 开始任务

- 工程探索前阅读根目录 `docs/agents/domain.md`，按其中入口加载领域文档。
- 开发前阅读[整合规格 #22](https://github.com/leiyihai/MyFigma/issues/22)，再读取关联任务的最新正文与确认评论。本机 `需求/` 文档不入库，仅作访谈与草稿参考；实现和验收状态从本目录 README 及关联记录核对。

## 模块边界

- Rust 本地助手、图集导入插件与独立九宫格插件分别构建；两个插件共用九宫格核心，不在运行时依赖彼此或 ui-studio。
- 原独立九宫格插件目录不在本目录修改范围内。

## 验证与交付

- 从扫描、导入和增量更新的公开流程验证用户可见结果，补充像素恢复和预览交互回归。
- 真实客户端验收，或排查 Figma 专属加载、通信、渲染故障时，先阅读 [真实客户端测试指南](docs/real-figma-testing.md)。
- 交付报告列明实际运行的验证及未验证项；只完成代码或测试替身时，不声称真实 Figma 已验收。
