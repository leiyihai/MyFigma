# 资源导入器

把游戏项目的私有图集和独立图片整理成 Figma 唯一主组件库，支持九宫格、原位增量更新、页面级用途分类和人工标签整理。Windows Rust 助手与两个 Figma 插件分别构建，均不依赖 ui-studio；两个插件运行时互不依赖，资源导入器的扫描和样本提交依赖本地助手。

## 启动与最小使用

1. 在 `local-helper` 执行 `cargo build --release --locked`，双击 `target\release\resource-helper.exe`，或用 `cargo run --release --locked` 启动。助手驻留托盘；正常退出会关闭端口，不安装服务或自启动项。
2. 两个插件各自执行 `npm ci`、`npm run build`，分别在 Figma 导入其根目录 `manifest.json`。这些是本地构建步骤，代理安装或更新依赖仍需事先获准。
3. 资源导入器首次使用时，从本机令牌文件配对 `http://localhost:38473`；成功后自动记住，可在设置中忘记。令牌不要贴到聊天、Issue、日志或文档。
4. 在管理项目中登记游戏根或私有图集目录，默认下拉只列长期维护项目；全部登记项目通过管理弹窗维护。可先登记助手的 `examples` 目录，得到恢复透明留白的红色和绿色两张散图。
5. 在对应游戏的独立 Figma 文件中选择空白页，扫描并核对摘要后导入。再次扫描按身份原位更新；错误名称、错绑或非空未绑定页会被拒绝。

插件只能协助打开助手文件夹或复制路径，不能保证从 Figma 直接启动 exe。若断连，先检查托盘中的助手进程，再重新连接；首次配对始终需要手动复制令牌。

## 当前工作流

- 扫描全部项目私有图集帧及未打包独立 PNG，不按布局引用过滤；布局只提供来源引用和九宫格统计。不完整扫描可导入成功部分，但不据此标记源缺失。
- 分类资源页维护唯一主组件；增量保留身份和人工覆盖，源删除只标记，取消与单项失败保留已成功结果，再次执行补齐。
- 用途默认七类，页面可自定义。分类顺序是「人工覆盖 > 页面命名规律 > 通用前缀 > 关键词 > 尺寸 > 未分类」，九宫格只表示拉伸属性。
- 主面板为 350×600，彩色标签点击即批量分类，最多四行、超出内部滚动；类别管理支持新增、改名和删除，另有会话内撤销和提交人工训练样本。详细行为与限制见插件说明。
- 九宫格原位编辑和项目参数通过 shared plugin data 在两个不同插件身份间共享，不依赖私有数据互读。需要核对图集时手动创建或更新实例对照页，普通导入不维护其结构。
- 正式分类没有接入视觉模型；训练样本只保存人工覆盖的来源身份和类别，不上传图片或访问远端。

## 验证方式

以下是开发时可复用的命令，**本次文档整理未重新运行功能测试或操作 Figma**。已安装依赖后，从各目录运行：

| 目录 | 命令 | 实际边界 |
| --- | --- | --- |
| `packages/nine-slice` | `npm run typecheck && npm test` | 切片规划与共享记录 |
| `nine-slice-plugin` | `npm run typecheck && npm test` | 公开插件消息入口、构建后的浏览器预览 |
| `local-helper` | `cargo fmt --check && cargo check --locked && cargo clippy --all-targets --locked -- -D warnings && cargo test --locked && npm test` | Rust 构建检查、真实子进程 HTTP/像素/持久化/托盘退出 |
| `atlas-import-plugin` | `npm run test:all` | 真实助手 → Workflow → 平台入口的流程与构建后 UI 交互 |

Node 测试钩子会构建相关产物。九宫格浏览器回归使用 Playwright Chromium，导入器使用系统 Chrome；未安装时先取得安装许可。Rust 原生测试目前没有单元用例，不能把 `cargo test` 的构建通过当作全部行为验证。

#21 完成评论记录导入器 88 个 Node、10 个浏览器用例通过，助手记录 27 个 Node 用例；这些是此前运行结果，具体平台跳过项以当次日志为准。Figma API 替身和浏览器消息宿主不证明真实裁剪、约束传播、实例尺寸或渲染。

- 独立小样验证过插件加载、localhost 配对、页面保护、拆图像素、原生搜索插入与实例交换；增量小样验证过原位更新、实例设计尺寸保持、源缺失保留及 63 项任务取消后补齐。
