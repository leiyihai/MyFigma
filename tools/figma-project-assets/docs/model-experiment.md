## 基线

用当时的名称关键词 + 尺寸比例规则在这 175 个样本上的准确率：

- 全样本：129 / 175 = **73.7%**
- 20 次分层 70/30 留出切分：平均 **74.3%**（范围 67.9%–79.2%）

> 这两个数字不是当前 #20 的统一门槛；g1048 的新口径见上文。模型和规则必须在相同数据与切分上比较，学习规律也必须只使用每折训练标签，不能先从全部标签学规则再评估留出集。

## 小模型尝试

### 通用视觉骨干横评

同一 175 个标签、同一 20 次分层 70/30 留出切分，使用预训练特征 + kNN：

| 模型 | 最高平均准确率 |
| --- | ---: |
| MobileNetV2-7 ONNX logits | 约 60% |
| MobileNetV3-Small | 52.9% |
| ConvNeXt-Tiny | 48.7% |
| EfficientNetV2-S | 50.9% |
| Swin-T | 50.4% |
| ViT-B/16 | 49.1% |
| DINOv2 ViT-S/14 | 52.5% |

DINOv2 的 52.5% 在表中并非最高值；MobileNetV2 约 60%、MobileNetV3 为 52.9%。这些历史候选均低于同轮规则基线 74.3%，提示用途分类不能只依赖更大的通用视觉骨干；不能由此断言它们在 g1048 同样落后于新基线。

### 1. MobileNetV2-7 ONNX + logits + kNN

- 输入：透明背景合成到黑/白底，缩放到 224×224；居中留白或拉伸
- 特征：ONNX 输出 1000 维 logits，L2 归一化
- 分类：kNN，cosine 相似度，k=3/5/7
- 10 次分层切分最佳平均准确率：**约 59.1%–60.0%**
- 单次留出集：**60.4%**

### 2. MobileNetV3-Small ImageNet 特征 + kNN

- 使用 torchvision 预训练 MobileNetV3-Small，移除分类头，取 576 维特征
- 透明图合成到黑底
- 20 次分层切分：
  - k=1：**52.9%**
  - k=3：**49.6%**
  - k=5：**47.8%**
  - k=7：**46.4%**

## 结论

在这轮 g1108 历史小样本实验中，所有候选都没有超过当时的规则基线（74.3%），因此**未接入正式导入流程**，也未据此新增模型文件或推理依赖。此结论不代替 #20 在 g1048 人工标签上的后续评估。

可能原因：

- ImageNet 语义与游戏 UI 用途不一致；
- 175 个样本很小，且“未分类/底板/按钮”的视觉边界依赖布局与文字语义；
- 只用图片、去掉名称和布局信息，丢失了现有规则最强的信号；
- 九宫格拉伸属性被刻意从标签中剥离，模型无法借它判断按钮/进度条。

## 后续可选方向

1. 继续扩充标签，尤其底板、按钮、进度条、未分类的边界样本；
2. 在强骨干上训练轻量分类头，而不是直接用通用模型 logits 做 kNN；
3. 将图片特征与名称、尺寸、布局引用组合，做混合分类器；
4. 如果仍不超过规则基线，保留规则分类，不做模型接入。
