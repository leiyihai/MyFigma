# 界面对齐与追问关卡

制作新的 HTML 预览，或修改已有预览的重要界面决策前，先执行本关卡。功能基本明确时沿用需求，追问聚焦 UI 设计；明确的局部调整直接执行，只读检查不要求重做访谈。

## 1. 读取并识别分歧

- 先按下面[需求文档怎么读](#需求文档怎么读)分层阅读需求、参考图和已有产物，复用上下文中的回答。能从文件或工具查明的事实先自行检查，不让用户重复提供。
- 将本次界面决策分为已明确、存在歧义、有明显设计风险三类。需求中的功能描述不必然决定其界面形式，例如“查看详情”并未确定使用弹窗、侧栏还是独立页。
- 检查信息层级、布局比例、内容密度、导航与返回、弹窗／侧栏关系、主次操作位置、滚动和固定区、图标文字表达，以及长内容、空态、加载与禁用反馈。只对存在实际分歧或风险的项提问，不逐项机械发问。
- 功能规则只有影响布局、控件、状态表现或操作路径时才追问；不审问与当前界面无关的经济、存档或后端规则。非关键缺失可采用在对话中简短说明的样例假设。

**完成标准**：每个重要界面决策都有需求依据、已确认答案，或进入待讨论清单；发现的明显风险能指出具体控件和使用场景。

### 需求文档怎么读

需求文档通常混着三层内容，读的时候先分开，不要整段搬进界面：

1. **界面可见内容**——玩家在界面上读到的字：标题、说明、按钮、状态文字、数值、空态文案。直接采用。
2. **界面可体验的行为**——打开、关闭、切换、状态变化、动效时长、进入某个状态的条件。落成原型里的交互，不落成界面上的说明文字。
3. **实现规则**——状态矩阵、判定条件和时间约束中，影响玩家可见状态或可操作性的部分，须模拟到交互里；数据结构、埋点和后端细节只作实现参考。规则措辞不直接印在界面或旁注里；验收清单用于检查覆盖，待确认事项用于识别分歧。

例外：需求里点名的 UI 区块（例如「功能说明区」）照做，但只用它给的短句和它要展示的要点，不把整段规则原文抄上去。

多来源先遵循用户当前明确要求和已确认决定，再以用户指定的权威需求为依据；参考图、已有原型用于补充。辅助说明与 `@` 文件一起读取，`@` 只是指定来源，不自动压过用户当前说明。规则与界面表达冲突且影响关键路径、布局或状态时，列出具体差异，确认后再做，不静默舍弃规则。

需求文件从哪来：优先用用户指定路径或对话里明确的需求；已有足够简述时不强求文档。缺少来源时列出项目 `需求/` 下候选供选择，不自行选版本。文件名版本与修改时间只是线索，不取代用户指定版本。

需求点名评审工具栏、压缩时间或演示入口时，先与“默认只呈现产品界面”的约定对齐：确认保留、移到独立状态入口，还是用产品内路径体验，不直接删除而失去验证途径。

## 2. 分轮追问

- 把决策按依赖关系展开，每轮只问前置条件已经明确的问题；需要等上题答案的问题留到下一轮。
- 每题包含具体问题、推荐方案、理由和主要取舍；可以用“是”接受推荐，也允许用户提出其他方案。
- 用具体场景挑战设计，例如双侧栏展开后内容是否过窄、仅图标指标是否可辨、主按钮是否被滚动移出视口，而不是泛问“还有要求吗”。
- 回答后更新已确认项，只追问由答案引出的新分歧。无实际未决项时收敛，不为模仿拷问而强行增加问题或无限扩展需求。

### 图标与文字

- 按控件语义、惯例、辨识度和空间决定使用图标、文字或两者组合，二者不互斥。
- 惯常且清晰的返回、关闭可只用图标；不易识别的业务操作优先保证文字可理解，必要时配图标。指标可用图标加数值，含义容易混淆时讨论标签、提示或其他表达。
- 装饰图标不默认添加。发现辨识风险或视觉冗余时，针对那个控件给出备选，不套用“有图标就无文字”的总规则。
- 图标按钮可保留不可见的可访问名称，不因取消可见说明而失去辅助技术可读性。

**完成标准**：影响本次 UI 的歧义和风险已有明确选择；尚未解决的重要问题继续讨论，不能以 AI 自选方案冒充用户决定。

## 3. 确认界面方案后再写 HTML

- 汇总简短界面方案：主要分区与比例、内容密度、导航／弹层关系、操作层级、关键图标文字选择，以及需求交互的表现方式。已确认内容简写，不要求用户重答。
- 在对话中给出简短摘要，等待用户明确确认理解一致，再创建或重构 HTML。用户只同意开展追问不等于确认具体界面方案。
- 后续涉及重要界面决策的变更，重新确认受影响部分；不重复询问已确认且未变化的内容。

**完成标准**：用户已确认具体界面方案，重要分歧均已解决。此确认只覆盖该方案，不自动授权 Figma 写入；版本认可与写入范围由 `ui-design-figma` 核对。

## 精简交付

HTML 阶段默认只交付原型文件，不另建或更新方案说明、交互清单、验收报告等补充文档，用户明确要求时除外。方案和确认以对话为依据，重要变更只重新确认受影响部分；交付时给出文件路径，仅对必要缺口或未验证项作简短提示，不复述完整方案。
