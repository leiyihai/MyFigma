# Game UI Design

本词汇表区分交互沟通、静态状态展示与换皮维护中的设计产物。

## Language

**界面对齐（UI Alignment）**：
设计者与 AI 围绕界面歧义和风险形成一致方案的讨论过程，关注视觉结构、控件表达和交互呈现，而非重新定义整套业务。
_Avoid_：功能审查、需求复述

**HTML 预览（HTML Preview）**：
用于确认界面方案与操作反馈的可交互灰阶原型，兼顾分区、比例、内容层级和需求交互，不是真实业务应用。
_Avoid_：纯静态线框、最终美术稿

**布局预览（Layout Preview）**：
本项目对 HTML 预览的旧称，默认同样包含需求中的交互，不仅是静态布局。
_Avoid_：将其理解为默认不可点击的草稿

**界面可见内容（Visible Interface Content）**：
玩家在界面上读得到的文字与数值——标题、说明、按钮、状态、空态；需求文档里的规则条文、状态矩阵、数据结构、埋点与验收清单不属于此类。
_Avoid_：需求原文、规则说明

**实现规则（Implementation Rule）**：
决定界面怎么变、什么时候变的约束，例如判定条件、状态迁移和时间实现；它落成原型的交互，但不以文字形式出现在界面上。
_Avoid_：界面文案、帮助说明

**原型工艺（Prototype Craft）**：
灰阶交互原型在间距、层级、字号、文案、图标和动效上的制作质量，与最终美术风格相区分。
_Avoid_：美术风格、最终视觉稿

**设计台（Design Studio）**：
承载原型预览、渲染观察和尺寸检查的工具，与决定任务步骤和完成标准的设计技能相区分。
_Avoid_：设计流程、设计技能

**设计台画布（Studio Canvas）**：
设计台中显示原型、供设计者体验当前版本的区域，不是产品界面的一部分。
_Avoid_：产品页面、原型说明区

**换皮维护源（Skinning Source）**：
设计者后续修改外观和替换资源的权威设计内容，包括共享组件、必要状态、代表性布局及资源。
_Avoid_：待修改的全部页面、演示副本

**换皮批次（Skinning Batch）**：
一次交给设计者处理的独立美术源及其效果展示范围，不等于完整功能或全部界面状态。
_Avoid_：全量交付、全部待换皮组件

**待替换区（Skinning Workspace）**：
集中展示换皮维护源的工作区域，不代表所有界面状态的集合。
_Avoid_：原型区、测试区

**结构组件（Structural Component）**：
承载控件或区域的布局、尺寸、文字及内容排列的可复用设计单元，与可替换的美术内容相区分。
_Avoid_：美术资源、整张图片

**拆分方案（Decomposition Proposal）**：
对原型中组件边界、独立维护、同组变体及嵌套复用关系的一组判断；待验收方案与已认可的维护意图区分。
_Avoid_：自动确认、已生成的 Figma 组件库

**拆分验收（Decomposition Acceptance）**：
对照原型和维护意图，检查组件边界与关系并决定接受或修正的过程，不等于从零手工拆分。
_Avoid_：逐个重拆、Figma 同步验收

**组件工作台（Component Workbench）**：
呈现原型组件、来源与维护关系，供检查拆分方案及必要纠偏的工具；与决定拆分标准的规范相区分。
_Avoid_：自动拆分算法、组件设计规范

**组件拆分标注（Component Decomposition Annotation）**：
对交互原型中组件的内容范围、组合层级与复用关系所作的显式说明，可来自 AI 准备或人工纠偏，用于表达维护意图。
_Avoid_：截图切块、网页样式编辑

**组件稿（Component Draft）**：
从交互原型中选取内容后独立整理的组件设计稿，保持所选内容的视觉表现，与原型自身的布局和交互相区分。
_Avoid_：选区截图、已生成的 Figma 主组件

**组件组（Component Group）**：
被明确归为同一组件的多个组件稿，包含一个主体及其他变体；与独立维护的组件相区分。
_Avoid_：自动相似项分组、已生成的 Figma 组件集

**嵌套复用（Nested Reuse）**：
一个组件稿显式引用另一个组件稿的关系，不因原型选区重叠而自动产生。
_Avoid_：内容相似、选区重叠

**主体（Primary Draft）**：
组件组中被指定为默认外观和基础结构参考的组件稿；其他变体不因其主体身份而自动继承它的全部修改。
_Avoid_：自动继承的父组件、Figma 主组件

**美术槽位（Artwork Slot）**：
结构组件中独立承载背景、底板或图标等可替换美术内容的位置，不等同于结构组件根节点的填充属性。
_Avoid_：根节点贴图、任意内容插槽

**适配预览实例（Responsive Preview Instance）**：
关联同一屏幕维护源、以不同设计尺寸并排展示布局适配的实例，不是独立换皮源或另一套交互状态。
_Avoid_：比例变体、缩放副本、冻结参考

**状态展示稿（State View）**：
用于展示某个页面或局部控件视觉状态的静态设计内容，不承担可点击流程演示。
_Avoid_：演示场景、另一套换皮维护源

**冻结参考区（Frozen Reference）**：
独立保留各批次换皮前外观、供后续视觉比对的只读参考，不随维护源修改而变化。
_Avoid_：共享实例副本、第二套维护源

**交互原型（Interaction Prototype）**：
用于模拟操作路径和界面反馈的可交互演示，本项目由 HTML 承担，不是真实业务实现。
_Avoid_：Figma 状态展示稿、业务系统
