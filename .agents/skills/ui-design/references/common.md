# 游戏 UI 共同约定

供四个任务技能共享；具体操作与验收由相应任务维护。

- 新建界面默认 **1280×720（16:9）**，仅做该尺寸。用户指定尺寸优先；修改已有稿保留原尺寸和已有预览。HTML 与 Figma 沿用同一约定，多比例按明确需求追加。
- 从对话、用户指定需求和当前产物恢复任务，只补缺失信息。明确局部修改不重跑无关访谈；改变重要布局、控件或操作路径时，重新确认受影响部分。
- 确认绑定具体方案／设计版本及范围，不绑定口令。加载技能不是授权，阶段切换请求不是版本认可；已知缺口在请求确认前说明，用户认可不改变验证事实。
- 默认在对话中交付方案、问题和必要缺口，不另造方案、交互清单或验收报告文件；用户明确要求文件时除外。
- 技能定义任务和完成标准，工具提供预览、测量或编辑能力。按运行环境选择工具，不把本机安装、profile 或面板状态写成项目通用前提。工具不足时明确区分静态检查、渲染、尺寸测量和实际操作的已验／未验状态。
- 继续任务读取当前内容，不以记忆覆盖用户同期调整。术语有歧义时查[术语表](GLOSSARY.md)。
