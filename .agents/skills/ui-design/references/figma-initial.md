# 首批搭建：够用的换皮基线

用于还没有本功能换皮基线的任务；共用维护与保护规则见[Figma 换皮维护](figma-ui.md)。不是“低质量版”，而是范围较小、能开始换皮的一批。

1. 确认用户认可的设计版本、目标文件与首批范围；复用已有相关资产。需要组件拆分／验收时，按[拆分规范](component-decomposition.md)由 AI 先准备，人验收关键边界，不要求人逐个手拆；未接通的工具能力明确保留缺口。
2. 选一个代表性主界面，保留主要区域、内容层级与控件搭配。列出本批真正需要独立换皮的源；同类面板／控件先做代表，有不同维护需求的样式不强行合并。
3. 主界面直接使用这些源的实例，使用户换皮后能看到整体效果；不只交付零散组件。其他 TAB、状态和次级界面只要能复用本批源，就暂缓，不先铺满。
4. 按本批维护路径检查、冻结原貌，交给用户换皮并暂停；共用规则已取得的有效证据不重复收集。

**完成标准**：代表主界面可看，独立换皮入口可定位，实际检查与未验项清楚，本批原貌参考可用，暂缓范围已说明。不是以全功能、所有变体或所有适配尺寸齐全判定完成。

**停止点**：等待用户完成本批换皮；只有用户明确就绪并指定后续范围，才进入[增量补齐](figma-expand.md)。
