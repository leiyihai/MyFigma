# 对齐游戏 UI

本任务只形成并确认方案，不创建 HTML 或写入 Figma。

1. 读[共同约定](../ui-design/references/common.md)和[界面对齐](../ui-design/references/ui-alignment.md)，按需查[术语](../ui-design/references/GLOSSARY.md)。读取用户指定需求、参考和当前产物，复用已确认答案。
2. 按依赖分轮讨论影响布局、控件、状态或操作路径的歧义；只问查不到的决定。明确局部调整不重做无关访谈。
3. 给出简短方案摘要，含主要分区、层级、操作、关键状态和样例假设；重要分歧解决且用户认可该方案后，标明已确认。若尚未答复，停在待确认，不进入制作。

**交付**：对话中的方案与确认状态，不另建交接文件。确认只覆盖这版方案；后续制作由 `ui-design-prototype` 接手，Figma 写入另需版本与范围确认。
