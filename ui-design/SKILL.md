# Figwright Game UI

所有相对路径均相对于本技能目录。开始前阅读 [设计规范](references/figma-ui.md)，其中定义默认值、修改边界、Figwright 操作、布局、组件、原型及验收要求。

## 执行流程

只读任务仅执行现场读取与适用验收；已有界面仅修改受影响区域及其依赖。

| 步骤 | 操作 | 完成标准 |
| --- | --- | --- |
| 1. 确认桥接 | 发现 Figwright 工具，确认插件连接、版本兼容性、编辑模式及目标文件 | 已确认正确文件和页面，可执行本次操作；关键缺口明确 |
| 2. 规划结构 | 划分区域，逐轴确定尺寸模式，区分内容属性、组件状态和原型动作 | 明确组件清单、演示起点、核心路径、结果反馈及返回方式 |
| 3. 建立骨架 | 配置根 Frame 和 Auto Layout，复用组件，创建必要变体与内容属性 | 读取属性确认布局、实例关联和属性绑定，覆盖新增或修改的节点 |
| 4. 连接原型 | 先连接低保真核心路径，配置触发器、动作、目标及起始 Flow | 核心路径形成闭环，连接读回正确；需手动配置项已记录 |
| 5. 视觉完善 | 完善样式、字体、资源及对齐，截图检查后修正 | 视觉符合约定，结构和自适应能力保持有效 |
| 6. 验证交付 | 执行参考规范中的结构、尺寸、原型走查和保存检查 | 每项适用检查均有结果，提供目标位置、演示方式和待讨论事项 |

桥接不可用时报告具体阻塞，不擅自切换官方 Figma MCP、其他编辑器或开发网页。
